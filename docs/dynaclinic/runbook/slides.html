04 / the proposalDynamiClinic

A Meta-Controller makes the topology a variable

Two scores, one rule

Complexity C: how dense the case is (comorbidities, drugs, conflicting labs).
Uncertainty U: entropy of a generalist's first differential.

U > tau_u → adversarial
C <= tau_c → hierarchical
otherwise → collaborative

A Conflict Detector escalates collaborative to adversarial when the specialists diverge. tau_u is calibrated per model (gpt-6-luna: 0.15 multiple choice, 0.59 open-ended).

Hierarchicalspeed

Primary Care Agent as the hub; specialists only on request.

Collaborativebreadth

Imaging, Pathology/Lab, Pharmacology on a shared Blackboard; mesh exchange; Consensus Builder.

Adversarialdepth

Proponent defends H1, Opponent (Clinical Critic) attacks, Mediator decides.

Reviewed proposal, layers L0-L4: input gateway, Meta-Controller, communication topology, agent execution, data and infrastructure5 / 9

06 / what was builtDynamiClinic

Four pieces behind the graph

10

Custom node types

Every DynaClinic step in the graph is a new DevAll node written in Python: triage, uncertainty sweep, primary care, care team, divergence gate, mesh, proponent, critic, synthesizer, safety gate. One YAML file wires them.

3

Evaluation arms

Single: one model call answers. Static team: the full team and critic every time. Dynamic: DynamiClinic picks the mode. Same questions, same model.

3D

Office view

Imports any DevAll workflow; each agent is a character. On a hand-off the agents meet and talk, and each nameplate shows the agent's current role.

1,030

Automated tests

Run offline with a fake model, no API calls: mode rule, thresholds, safety gates, engine fixes. Real runs are kept separate.

dynaclinic/ (Python), yaml_instance/dynaclinic_mvp.yaml, the-delegation/ (React + Three.js). Stubs: FHIR/Neo4j, MCTS planner, BioBERT/Qdrant memory.7 / 9
