DynaClinic in 3D: runbook demo

One continuous recording of the runbook, step by step, in the three.js office. Three real cases on OpenAI gpt-6-luna: the Meta-Controller keeps one Primary Care Agent for a simple case, calls the Integrated Care Team for a complex one, and switches to the adversarial Clinical Critic when the specialists disagree. Captions name the runbook step and quote the run's own output. Idle stretches longer than 2.5 s are shortened; nothing else is cut or staged.
Note (2026-10-28): recorded before f14 and f15. The code now also computes an uncertainty score, adds a mesh exchange in collaborative mode and a Proponent / Opponent / Mediator debate in adversarial mode, and the 3D office shows agents meeting on every hand-off; see the fact check and results.

Recorded 2026-10-27 at commit 8f27bff, fresh browser profile, backend on :6400, office on :3100. Click any step in the list to jump there.

Run it yourself

# from the repo root (git clone https://github.com/LaansDole/multi-agent-simulation)
env -u PYTHONPATH -u VIRTUAL_ENV uv run python server_main.py --port 6400

cd the-delegation
npx vite --port=3100 --host=127.0.0.1 --strictPort

Open localhost:3100/the-delegation/, then follow the steps in the list above. Case lines: data/dynaclinic/synthetic_cases.jsonl (A) and data/dynaclinic/demo_cases.jsonl (B, C). Full instructions, troubleshooting and the proposal mapping: runbook.
