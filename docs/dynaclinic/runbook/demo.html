DynaClinic in 3D: runbook demo

One continuous recording of the runbook, step by step, in the three.js office. Three real mock scenarios on OpenAI gpt-6-luna, one per mode: the Meta-Controller scores complexity C and uncertainty U, keeps one Primary Care Agent for a simple case (hierarchical), calls the Integrated Care Team with a mesh exchange for a complex but clear one (collaborative), and opens a Proponent / Opponent / Mediator debate when uncertainty is high (adversarial). Agents meet and talk on every hand-off. Captions name the runbook step and quote the run's own output. Idle stretches longer than 2.5 s are shortened; nothing else is cut or staged.

Recorded 2026-10-28 at commit be54e5a (after f14 to f23), fresh browser profile, backend on :6400, office on :3100. Click any step in the list to jump there.

More: benchmark results (single vs dynamic vs static on MedQA and the synthetic set), the fact check against the reviewed proposal, and the 8-slide deck (PDF). A generic DevAll workflow in the same 3D office, with agents meeting on every hand-off: demo_hospital in 3D. The 3D app also takes any clinical scenario in plain words, not only multiple-choice questions.

Mock scenarios from dynaclinic_mvp.yaml (Mock scenarios panel, Insert, Enter). Care team: each answering specialist's top choice and its probability. Thresholds: tau_c 0.5, tau_u 0.15 for multiple choice (calibrated for gpt-6-luna), divergence tau 0.25. Layer 4 safety gates (A_SAD, T_SAD) passed in all three; S_NAP is a stub. U is sampled (k = 5), so a re-run can land in another mode: in this session the apixaban case went collaborative (U 0.13), and earlier runs of case C went adversarial at U 0.51.

Run it yourself

# from the repo root (git clone https://github.com/LaansDole/multi-agent-simulation)
env -u PYTHONPATH -u VIRTUAL_ENV uv run python server_main.py --port 6400

cd the-delegation
npx vite --port=3100 --host=127.0.0.1 --strictPort

Open localhost:3100/the-delegation/, then follow the steps in the list above. Case lines: data/dynaclinic/synthetic_cases.jsonl (A) and data/dynaclinic/demo_cases.jsonl (B, C). Full instructions, troubleshooting and the proposal mapping: runbook.
