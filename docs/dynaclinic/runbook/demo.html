DynamiClinic in 3D: runbook demo

In one recordingThree real mock scenarios on OpenAI gpt-6-luna, one per mode, run step by step through the runbook in the three.js office. The Meta-Controller scores complexity C and uncertainty U, keeps one Primary Care Agent for a simple case (hierarchical), calls the Integrated Care Team with a mesh exchange for a complex but clear one (collaborative), and opens a Proponent / Opponent / Mediator debate when uncertainty is high (adversarial). Agents meet and talk on every hand-off.

mode(C, U) = adversarial if U > τu hierarchical if C ≤ 0.5 collaborative otherwise
(1)

τu is 0.15 for multiple choice (calibrated for gpt-6-luna). The Conflict Detector can still move a collaborative team to adversarial when the specialists' divergence reaches τ 0.25.

The 3D app also takes any clinical scenario in plain words, not only multiple-choice questions.

Run it yourself

# from the repo root (git clone https://github.com/LaansDole/multi-agent-simulation)
env -u PYTHONPATH -u VIRTUAL_ENV uv run python server_main.py --port 6400

cd the-delegation
npx vite --port=3100 --host=127.0.0.1 --strictPort

Open localhost:3100/the-delegation/ and follow the steps above. Case lines: data/dynaclinic/synthetic_cases.jsonl (A) and data/dynaclinic/demo_cases.jsonl (B, C). Full instructions, troubleshooting and the proposal mapping are in the runbook.
